# **1941. Check if All Characters Have Equal Number of Occurrences**

## **Problem Statement**
Given a string `s`, return `true` if the string is "good," otherwise return `false`.

A string `s` is considered "good" if **all the characters that appear in `s` have the same frequency**.

### **Constraints**
- \( 1 \leq s.length \leq 1000 \)
- `s` consists of lowercase English letters only.



## **Thought Process**

### **Understanding the Problem**
To determine if a string is "good," we need to verify that:
1. All the characters in the string that appear at least once have the **same frequency**.
2. If even one character deviates from this frequency, the result should be `false`.



### **Approach**

1. **Count Character Frequencies:**
   - We can count how many times each character appears in the string using a **hashmap** (or dictionary in Python).
   - Each key in the hashmap will represent a character, and the corresponding value will represent the frequency of that character.

2. **Verify Frequency Consistency:**
   - After populating the hashmap, we check if **all values (frequencies)** in the hashmap are the same.
   - If all the frequencies match, the string is "good." Otherwise, it's not.


## **Code**

```python
class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        # Step 1: Count frequencies of each character
        characters = {}

        for i in s:
            if i in characters:
                characters[i] += 1
            else:
                characters[i] = 1
        
        # Step 2: Verify all frequencies are equal
        k = None
        for frequency in characters.values():
            if k and k != frequency:
                return False
            k = frequency

        return True
```

## **Complexity Analysis**

- **Time Complexity:**
  - Counting character frequencies: \( O(n) \), where \( n \) is the length of the string.
  - Verifying frequency consistency: \( O(k) \), where \( k \) is the number of unique characters (at most 26 for lowercase letters).
  - Total: \( O(n) \).

- **Space Complexity:**
  - The hashmap `characters` stores up to 26 keys for lowercase letters.
  - Space usage: \( O(1) \) since the size of the hashmap is bounded by the alphabet size.
